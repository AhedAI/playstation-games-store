PlayStation Games Store 🎮
A Java-based desktop application for a PlayStation games store, developed using Object-Oriented Programming (OOP), Java Swing, JDBC, and PostgreSQL.
🛠️ Technologies Used
Java — Application logic and Object-Oriented Programming.
Java Swing — Graphical User Interface (GUI).
JDBC — Database connectivity.
PostgreSQL — Relational database.
Supabase — Cloud database service.
✨ Project Components
Game.java — Game model.
GameDAO.java — Database access operations.
GameGUI.java — Graphical user interface.
GameApp.java — Application functionality.
Main.java — Application entry point.
PS4Game.java — PlayStation 4 game class.
PS5Game.java — PlayStation 5 game class.
⚙️ Configuration
The application uses environment variables for database credentials:
DB_URL
DB_USER
DB_PASSWORD
Configure these variables before running the application. Never publish database passwords or other sensitive credentials.
🚀 Getting Started
Clone or download this repository.
Open the project in a Java IDE, such as IntelliJ IDEA.
Ensure Java and the PostgreSQL JDBC driver are configured.
Configure the required database environment variables.
Run Main.java.
Note: A successful database connection requires valid credentials, a reachable database, and the appropriate database configuration.
🎯 Purpose
This project demonstrates practical skills in Java programming, object-oriented design, graphical user interface development, and relational database connectivity.
